## Abstract

* goal
  * empirical scaling laws for language model performance ABOUT cross-entropy loss

* cross-entropy loss | 10^7 tested data /
  * `(modelSize)^(-α)`
  * `(datasetSize)^(-β)`
  * `(computeUsedForTraining)^(-γ)`
  * NOT depend heavily on
    * network width
    * network depth

* overfitting 
  * == `(model/dataset size)^a`

* training speed
  * == `(model size)^b`

* relationships
  * allow us to 
    * determine the optimal allocation -- of a -- fixed compute budget

* loss
  * := function / measure errors
  * types
    * cross-entropy 
    * mean squared
    * ...

* cross-entropy
  * allows
    * measure how accurate LLMs forecast the NEXT word | text

* Larger models -> MORE sample-efficient
  * _Example:_
    * small model
      * if you want to reach loss == 2.5 -> you need 1M samples 
    * big model:
      * if you want to reach loss == 2.5 -> you need 100k samples

* optimal compute-efficient training
  * == ⭐️training very large models | modest amount of data / stop significantly BEFORE convergence⭐️
    * _Example of "modest amount of data":_
      * 100GB of data vs 1TB of data
    * _Example of "stop significantly BEFORE convergence":_ 
      * Epoch 1: Loss 4.0
      * Epoch 50: Loss 2.5
      * Epoch 100: Loss 2.1  ← stop HER
      * Epoch 500: Loss 2.0  ← NOT get this point of low better
      * Epoch 1000: Loss 2.0 ← convergence
